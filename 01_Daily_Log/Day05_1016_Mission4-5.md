## [오늘 목표]

- Grad-CAM으로 모델의 판단 근거 확인, 결과 데이터 정의, Risk Level 설계 (Mission 5)
- 최종 보고서 작성

## [선택한 방법]
- **분석 노트북** (`04_Analysis_GradCAM.ipynb`): 저장된 가중치를 불러와 학습 없이 분석
  - E0 vs E1b 지표·혼동행렬 나란히 비교
  - 임계값 0.05 ~ 0.95별 민감도·특이도 (검증셋만 사용)
  - FN·FP 이미지 직접 확인
  - Grad-CAM 직접 구현 (ResNet18 `layer4`) + **테두리 집중 비율**(열지도가 바깥 15%에 몰린 비율) 지표 추가
  - Risk Level(Low < 0.1 / Medium / High ≥ 0.9) 기준을 검증셋으로 점검, 테스트 624장 결과 데이터 csv 저장

## [선택 이유]
- 리더보드 숫자만으로는 모델이 **무엇을 근거로** 판단하는지 알 수 없음 → Day01부터 걱정한 "검은 여백 = 폐렴" 지름길을 직접 확인해야 함
- Grad-CAM을 라이브러리 대신 직접 구현한 이유: 원리(기울기 평균 × 특징 지도)를 내 언어로 설명하기 위해
- 테두리 집중 비율을 추가한 이유: 지름길 학습 여부를 눈으로만 보지 않고 숫자로 비교하기 위해
- 임계값·Risk Level 기준을 검증셋으로만 정한 이유: 테스트 비율에 맞추면 Data Leakage

## [결과]

| 모델 (검증셋) | Accuracy | AUC | Sensitivity | Specificity | FN | FP |
|---|---|---|---|---|---|---|
| Before: E0 Baseline | 0.9454 | 0.9832 | 0.9433 | 0.9515 | 44 | 13 |
| **After: E1b** | **0.9799** | **0.9979** | **0.9768** | **0.9888** | **18** | **3** |

- 저장된 가중치로 다시 평가한 값이 03_Experiments 기록과 **완전히 같음** (재현 확인)
- **임계값**: 0.5 → 0.2로 낮추면 FN 18 → 10, FP 3 그대로 → 검증에서는 0.2가 더 좋지만, 테스트는 폐렴 쪽으로 기울기 쉬워(E5 경험) **대회 제출은 0.5 유지**, 낮은 임계값은 Risk Level에 반영
- **오답**: FN 18장은 확률 0.001~0.06으로 확신하며 틀림 / FP 3장은 **모두 기울어진 이미지**

| Grad-CAM 그룹 | 테두리 집중 비율 | 관찰 |
|---|---|---|
| 맞힌 정상 (TN) | 0.21 | 폐·심장 중앙 |
| 놓친 폐렴 (FN) | 0.15 | 정상과 같은 중앙 패턴 |
| 맞힌 폐렴 (TP) | 0.47 | 폐 하부 + 가장자리 |
| **오진한 정상 (FP)** | **0.68** | **검은 모서리** |
| 테스트 | 0.46 | 폐렴 판정 사례에서 몸통 바깥쪽 |

| Risk Level (검증셋) | 실제 정상 | 실제 폐렴 |
|---|---|---|
| Low (< 0.1) | 264 | 10 |
| Medium (0.1 ~ 0.9) | 3 | 26 |
| High (≥ 0.9) | 1 | 740 |

- Medium 비율: 검증 2.8% → 테스트 **9.0%** (처음 보는 형태의 이미지에서 확신도 하락)

## [인사이트]
- **숫자만으로는 모델을 믿을 수 없다** — 리더보드 0.94의 모델도 오진할 때는 폐가 아니라 검은 모서리를 보고 있었음 → Day01 EDA의 걱정이 실제로 확인됨
- **확신하며 틀린 FN은 임계값으로 못 잡는다** → AI 결과만으로 정상 처리하지 않고 의료진 확인이 반드시 필요 → Risk Level 설계의 근거
- **검증셋에서 좋은 임계값이 테스트에서도 좋은 건 아니다** — 분포가 다르면 임계값도 그대로 옮길 수 없음
- **Medium 비율 자체가 경고등이 될 수 있다** — 검증 2.8% → 테스트 9.0%처럼, 모델이 덜 확신하는 비율이 갑자기 늘면 새로운 형태의 데이터가 들어왔다는 신호로 쓸 수 있음

**💡 Reflection Questions**
- **잘 맞추는 경우의 특징은?** → 정상은 확률 0.00으로 확신, Grad-CAM이 폐·심장 중앙에 모임
- **틀리는 경우의 공통 패턴은?** → FN은 폐가 비교적 깨끗해 보이는 사례(확신하며 틀림), FP는 3장 모두 기울어져 검은 모서리가 있는 이미지
- **Confusion Matrix로 알 수 있는 것은?** → 정확도 하나로는 안 보이는 실수의 종류와 개수
- **Sensitivity와 Specificity의 의미는?** → 민감도: 실제 폐렴 중 맞힌 비율(낮으면 환자를 놓침) / 특이도: 실제 정상 중 맞힌 비율(낮으면 정상인을 오진)
- **위험한 판단을 할 수 있는 상황은?** → 경미한 폐렴, 기울어졌거나 여백이 큰 촬영본, 학습과 다른 형태의 이미지(다른 병원·장비)
