# Day 04 — 2026.10.16 (금) · Mission 3 마무리

> E4는 10/8에 학습만 해두고 리더보드 제출·분석을 못 했던 것을 오늘 이어서 진행함

## [오늘 목표]
- 학습 방식 전략 2가지(클래스 가중치 손실, 학습률 스케줄러)를 실험하고 최종 모델 결정 (Mission 3 마무리)
- 최종 파이프라인으로 처음부터 다시 실행해 재현성 확인

## [선택한 방법]
- **E4**: E1b + 클래스 가중치 손실 (정상 1.944 / 폐렴 0.673) — 학습 방식
- **E5**: E1b + 코사인 학습률 스케줄러 (1e-4에서 시작해 5 에폭 동안 점점 감소) — 학습 방식
- **최종 파이프라인** (`Final_Pipeline.ipynb`): 처음부터 "모두 실행"으로 E1b 재현

## [선택 이유]
- **E4**: 정상이 폐렴의 1/3밖에 안 되므로, 정상을 틀렸을 때 벌점을 키우면 정상 판단이 좋아질 것이라 예상 (Mission 0 가설 1)
- **E5**: E1b의 train loss가 4 → 5 에폭에서 0.0125 → 0.0161로 **오히려 올라감** → 막바지에도 학습률이 커서 흔들린 것으로 보고, 학습률을 점점 줄이면 안정될 것이라 판단
- 두 실험 모두 E1b에서 **하나만** 바꿔 효과를 분리

## [결과]

| 실험 | Val Acc | Val AUC | Sens | Spec | FN | FP | 테스트 정상 예측 비율 | 리더보드 |
|---|---|---|---|---|---|---|---|---|
| E1b (Before) | 0.9799 | 0.9979 | 0.977 | 0.989 | 18 | 3 | 0.386 | **0.9407** |
| E4 (+가중치 손실) | 0.9684 | 0.9984 | 0.960 | 0.993 | 31 | 2 | 0.388 | 0.9327 |
| E5 (+코사인 스케줄러) | 0.9885 | 0.9983 | 0.988 | 0.989 | 9 | 3 | 0.341 | 0.9375 |

- **E4**: FP 3 → 2로 줄었지만 FN 18 → 31로 증가. 테스트 정상 비율은 같았지만 624장 중 25장의 예측이 바뀌었고, 그중 E1b가 15장·E4가 10장을 맞힘 → 리더보드 하락
- **E5**: 가설대로 loss가 끝까지 내려감(0.0039 → 0.0038), 검증 FN 18 → 9로 절반. 그러나 테스트 정상 예측 비율 0.341로 하락 → 리더보드 하락
- **최종 모델 = E1b 유지**

- **재현성**: Final_Pipeline을 처음부터 실행 → 검증 지표 기록과 동일, 테스트 예측이 제출 파일과 **0 / 624** 차이

## [달성도]
- **실험(가설 기준): 실패** — E4·E5 모두 검증은 좋아졌지만 리더보드는 E1b보다 낮음
- **과제(과정 기준): 성공 (100%)** — Mission 3 완료, 최종 모델 E1b 확정, 재현성 증명(0 / 624)
- 필수 규칙 "모델 변경 외 개선 전략 2개 이상" 충족: Crop(데이터), 가중치 손실·스케줄러(학습 방식) 시도와 실패 원인 분석 기록

## [인사이트]
- **검증 점수가 오른 실험이 전부 리더보드에서는 떨어졌다** (E2·E4·E5) → 학습과 테스트의 형태가 달라서 검증셋으로는 최종 모델을 고를 수 없음
- **테스트 정상 예측 비율이 이번에도 리더보드 방향을 맞혔다** (E5: 0.386 → 0.341, 점수 하락) → 간접 지표의 유용성 재확인. 다만 E4처럼 비율이 같아도 오류가 상쇄될 수 있어 만능은 아님
- **AUC가 같아도 실수의 종류는 다를 수 있다** — E4·E5 모두 AUC가 소수점 넷째 자리까지 같은 에폭 중 먼저 나온 에폭이 선택됐고, 뒤 에폭의 민감도가 더 높았음. AUC는 임계값과 무관한 지표이기 때문 → 에폭 선택 기준의 한계
- **가설이 맞아도 결과가 좋아지지 않을 수 있다** — E5에서 "학습이 안정될 것"이라는 가설은 맞았지만, 그게 테스트 성능으로 이어지진 않았음

**💡 Reflection Questions**
- **Baseline 대비 성능이 실제로 개선되었나요?**
  → 리더보드 0.7468 → 0.9407(+19.4%p), 검증 FN 44 → 18·FP 13 → 3. 검증-리더보드 격차도 19.9%p → 3.9%p로 줄어듦
- **성능 변화의 원인은?**
  → 사전학습 모델을 **전체 미세조정**한 것이 핵심. 분류층만 학습한 E1a는 0.8333에 그침 → X-ray에 맞게 특징 자체를 고쳐야 학습·테스트 형태 차이를 견딜 수 있었음
- **예상과 다른 결과의 이유는?**
  → E4·E5는 검증에서 좋아졌지만 테스트 정상 예측 비율이 낮아지거나 예측이 바뀌면서 리더보드가 떨어짐. 검증셋은 학습셋과 같은 형태라 테스트 형태에서 생기는 문제를 잡아내지 못함
- **데이터 누수는 없었나요?**
  → 검증셋은 에폭 선택에만, 임계값·Risk Level 기준도 검증셋으로만 정함. 테스트는 예측·관찰에만 사용. 단, 환자 단위 분리는 불가능해 한계로 기록
