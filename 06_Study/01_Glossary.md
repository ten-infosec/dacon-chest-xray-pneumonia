# 핵심 용어집 — 흉부 X-ray 폐렴 분류 (DACON)

> 읽는 법: **쉬운 뜻** → **이 프로젝트에서는** 순서로 읽기.
> "이 프로젝트에서는" 줄을 내 입으로 말할 수 있으면 그 용어는 숙지한 것.

---

## 1. 문제와 데이터

| 용어 | 쉬운 뜻 | 이 프로젝트에서는 |
|---|---|---|
| **이진 분류** (Binary Classification) | 답이 두 개 중 하나인 문제 | 정상(0) / 폐렴(1) |
| **클래스 불균형** | 한쪽 답이 훨씬 많은 데이터 | 정상 1,341장(25.7%) vs 폐렴 3,875장(74.3%), 2.89배 |
| **EDA** (탐색적 데이터 분석) | 모델 만들기 전에 데이터를 뜯어보는 단계 | 분포·크기·샘플·검은 여백 비율을 확인 |
| **패딩** (Padding) | 사진을 정사각형으로 맞추려고 덧댄 빈 공간 | 학습 이미지에 검은 패딩이 있음, 폐렴이 더 많음 (17.6% vs 31.5%) |
| **분포 차이** (Distribution Shift) | 연습 문제와 시험 문제의 생김새가 다른 것 | 학습: 224×224 + 검은 여백 / 테스트: 원본 크기, 여백 없음 |
| **Resize** | 이미지 크기를 강제로 맞추는 것 (비율이 바뀌면 늘어나거나 찌그러짐) | 모든 이미지를 224×224로 맞춤 |
| **Crop** | 이미지 일부를 잘라내는 것 | E2에서 검은 여백을 잘라냄 → 실패 |

## 2. 검증과 평가

| 용어 | 쉬운 뜻 | 이 프로젝트에서는 |
|---|---|---|
| **검증셋** (Validation Set) | 학습에 안 쓰고 남겨둔 모의고사 | train의 20% |
| **층화 분할** (Stratified Split) | 나눌 때 정상·폐렴 비율을 양쪽에 똑같이 유지 | 8:2로 나누고 파일(`split_train/valid.csv`)로 고정 |
| **Seed** | 무작위 결과를 매번 똑같이 만드는 번호 | 42 |
| **Accuracy** (정확도) | 전체 중 맞힌 비율 | 대회 채점 기준. 단, 전부 폐렴이라 찍어도 74% |
| **혼동행렬** (Confusion Matrix) | 맞힘/틀림을 4칸으로 나눈 표 | TP·TN·FP·FN 개수 확인 |
| **TP / TN** | 폐렴을 폐렴으로 / 정상을 정상으로 맞힘 | |
| **FN** (False Negative, 거짓 음성) | 폐렴인데 정상이라 함 = **환자를 놓침** | E1b 검증 18장 — 의료에서 가장 위험 |
| **FP** (False Positive, 거짓 양성) | 정상인데 폐렴이라 함 = **오진** | E1b 검증 3장 |
| **민감도** (Sensitivity) | 실제 폐렴 중 맞힌 비율 | 0.977 — 낮으면 환자를 놓침 |
| **특이도** (Specificity) | 실제 정상 중 맞힌 비율 | 0.989 — 낮으면 정상인을 오진 |
| **임계값** (Threshold) | 확률이 몇 이상이면 폐렴으로 볼지 정하는 기준선 | 0.5 유지 (검증에선 0.2가 좋았지만) |
| **ROC-AUC** | 임계값을 바꿔가며 본 "폐렴과 정상을 얼마나 잘 구분하나" 점수 (1이 만점) | 모델 판단의 주 지표. E1b 0.9979 |
| **리더보드** (Public / Private) | 대회 점수판. Public은 테스트 일부로 채점한 중간 점수 | 최종 0.9407, 마감 후 Private로 재채점 |
| **간접 지표** | 정답 없이도 방향을 짐작하게 해 주는 숫자 | **테스트 정상 예측 비율** (실제 약 0.375). 이 값이 떨어지면 리더보드도 떨어짐 |

## 3. 모델과 학습

| 용어 | 쉬운 뜻 | 이 프로젝트에서는 |
|---|---|---|
| **CNN** (합성곱 신경망) | 이미지를 작은 창으로 훑으며 무늬를 찾는 모델 | Baseline SimpleCNN |
| **Baseline** | 비교 기준이 되는 출발점 모델 | SimpleCNN, 128×128, 2 epochs → 0.7468 |
| **사전학습** (Pre-training) | 큰 데이터로 미리 공부시켜 둔 모델 | ImageNet(일상 사진 약 100만 장)으로 학습된 가중치 |
| **전이학습 / 미세조정** (Fine-tuning) | 미리 공부한 모델을 내 문제에 맞게 조금 더 학습 | 모든 층을 학습(E1b) |
| **Freeze** (층 고정) | 일부 층은 학습 안 하고 그대로 둠 | E1a: 분류층만 학습 → 0.8333 |
| **ResNet18** | 18층짜리 CNN. 층을 건너뛰는 지름길 연결(Residual)로 깊어도 학습이 잘 됨 | 데이터 양에 비해 적당히 가벼워서 선택 |
| **분류층** (fc layer) | 모델 맨 끝에서 최종 답을 내는 층 | 1000개 클래스 → 2개로 교체 |
| **에폭** (Epoch) | 학습 데이터 전체를 한 번 다 보는 것 | 5 epochs |
| **학습률** (Learning Rate) | 한 번에 가중치를 얼마나 크게 고칠지 | 1e-4 (0.0001), 사전학습 지식을 덜 망가뜨리려고 작게 |
| **Adam** | 학습률을 상황에 맞게 알아서 조절해 주는 최적화 방법 | 기본 옵티마이저 |
| **손실 함수** (Loss) | "얼마나 틀렸나"를 숫자로 나타낸 것. 학습은 이걸 줄이는 과정 | Cross Entropy |
| **클래스 가중치 손실** | 적은 클래스를 틀리면 벌점을 크게 | E4: 정상 1.944 / 폐렴 0.673 → FN 증가로 실패 |
| **학습률 스케줄러** | 학습하면서 학습률을 점점 바꾸는 장치 | E5: 코사인으로 점점 줄임 → 검증은 좋았지만 리더보드 하락 |
| **과적합** (Overfitting) | 연습 문제만 외워서 새 문제를 못 푸는 상태 | |
| **Best epoch 선택** | 검증 점수가 가장 좋았던 에폭의 모델을 저장 | 검증 AUC 기준 → AUC 동점 문제 발견 |
| **Softmax** | 모델 출력을 합이 1인 확률로 바꿈 | `[:, 1]`이 폐렴 확률 |

## 4. 이번 과제의 핵심 개념

| 용어 | 쉬운 뜻 | 이 프로젝트에서는 |
|---|---|---|
| **지름길 학습** (Shortcut Learning) | 진짜 근거 대신 우연히 정답과 겹친 단서로 맞히는 것 = **커닝** | "검은 여백 = 폐렴", Crop 후엔 "늘어난 이미지 = 폐렴" |
| **가로세로 비율** (Aspect Ratio) | 가로 ÷ 세로 | Crop 후 정상 1.19 / 폐렴 1.47 / 테스트 1.46 → 근본 원인 |
| **데이터 누수** (Data Leakage) | 시험 문제나 정답 정보가 학습·설정에 새어 들어가는 것 | 테스트는 예측·관찰에만, 임계값·Risk 기준은 검증셋으로만 |
| **환자 단위 분리** | 같은 환자의 사진이 학습과 검증에 나뉘지 않게 하는 것 | 파일명 익명화로 불가능 → 한계로 기록 |
| **재현성** (Reproducibility) | 다시 돌려도 똑같은 결과가 나오는 것 | Seed + worker Seed + cuDNN deterministic → **0 / 624** 차이 |
| **cuDNN deterministic** | GPU 계산을 매번 같은 순서로 하게 하는 설정 (조금 느려짐) | 재현성 확보용 |

## 5. 모델 해석과 서비스

| 용어 | 쉬운 뜻 | 이 프로젝트에서는 |
|---|---|---|
| **Grad-CAM** | 모델이 사진의 **어디를 보고** 판단했는지 보여주는 열지도 | 직접 구현, ResNet18 `layer4` 기준 |
| **특징 지도** (Feature Map) | 각 층이 찾아낸 무늬 위치 지도 | layer4 출력 |
| **기울기** (Gradient) | "이 부분을 바꾸면 답이 얼마나 바뀌나" | 기울기 평균 = 각 특징 지도의 중요도 |
| **Hook** | 모델 중간 계산값을 몰래 꺼내 보는 장치 | forward hook으로 특징 지도, `register_hook`으로 기울기 |
| **테두리 집중 비율** | 열지도가 바깥 15%에 몰린 비율 (고르게 퍼지면 약 0.51) | 내가 만든 지표. FP 0.68 = 검은 모서리를 봄 |
| **Risk Level** | 확률을 위험 등급으로 나눈 것 | Low < 0.1 / Medium / High ≥ 0.9 |
| **분포 변화 감지** (모니터링) | 새 데이터가 이전과 달라졌는지 알아채기 | Medium 비율 검증 2.8% → 테스트 9.0% |
