# 공식 Baseline 분석

> 출처: 데이콘 제공 `[Baseline]_CNN를 활용한 흉부 X-ray 이미지 분류.ipynb`
> 목적: Baseline 구조와 한계를 정리하여 Mission 1(문제점 도출)과 Mission 2(개선 전략 설계)의 근거로 사용

---

## 1. Baseline 구조

| 단계 | 공식 Baseline 설정 |
|---|---|
| 전처리 | 흑백 변환(Grayscale) → 128×128로 축소(Resize) → 텐서 변환(ToTensor), 정규화·증강 없음 |
| 데이터 | train 전체로 학습, 검증셋 없음 |
| 모델 | SimpleCNN: Conv 2층(16→32 필터) + FC 1층, 처음부터 학습(사전학습 없음) |
| 손실함수 | CrossEntropyLoss (클래스 가중치 없음) |
| 최적화 | Adam, lr = 0.001 |
| 학습 | 2 epochs |
| 예측 | `argmax` → 0/1 값으로 제출 |

### SimpleCNN 구조

```
입력 (1, 128, 128)
→ Conv2d(1→16, 3×3) → ReLU → MaxPool(2)   : (16, 64, 64)
→ Conv2d(16→32, 3×3) → ReLU → MaxPool(2)  : (32, 32, 32)
→ Flatten                                  : 32,768
→ Linear(32,768 → 2)                       : 정상 / 폐렴 점수
```

## 2. Baseline의 한계

### ① 성능 측정 수단 부재 (가장 큰 문제)
- 검증셋이 없어 학습 중 확인 가능한 지표가 **train loss뿐**임
- 모델이 실제로 일반화하는지, 학습 데이터를 외운 것인지(과적합) 판단할 수 없음
- 성능 확인은 리더보드 제출에 의존해야 하나, 하루 제출 횟수 제한으로 반복 실험이 어려움

### ② 클래스 불균형 미고려
- 폐렴이 정상의 2.89배(74.3% vs 25.7%)이나 클래스 가중치·샘플링 조정이 없음
- 다수 클래스인 폐렴 쪽으로 예측이 치우칠 가능성이 높음

### ③ 해상도 손실
- 원본 224×224를 128×128로 축소 → 면적 기준 약 1/3만 남음
- 폐렴의 미세한 음영 등 세부 정보가 뭉개질 수 있음

### ④ 작은 모델 + 짧은 학습
- Conv 2층의 작은 모델을 2 epochs만 학습
- 사전학습 지식 없이 약 5천 장만으로 X-ray 특징을 학습하기에는 부족할 가능성

### ⑤ 임계값 고정
- `argmax`로 0/1을 결정 → 사실상 폐렴 확률 0.5 기준
- 대회 지표가 **Accuracy**로 확인되어 0/1 제출 자체는 적절함
- 다만 불균형·학습-테스트 분포 차이가 있는 상황에서 최적 임계값이 0.5가 아닐 수 있음 → 임계값은 **검증셋 기준**으로 검토

### ⑥ 재현성 장치 부재
- Seed 고정이 없어 실행할 때마다 결과가 달라짐
- 모델 저장 코드가 없어 학습 결과를 재사용할 수 없음

---

## 3. Baseline 재현 원칙

**모델과 학습 설정은 그대로 두고, 평가에 필요한 장치만 추가한다.**
→ 이후 "Baseline vs 개선 모델" 비교의 공정성을 확보하기 위함

| 그대로 유지 | 추가하는 것 |
|---|---|
| 128×128 흑백, SimpleCNN 구조 | Seed 고정 (재현성) |
| CrossEntropyLoss, Adam lr = 0.001 | 층화 분할 검증셋 (8:2) |
| 2 epochs | 검증 AUC · 민감도 · 특이도 · 혼동행렬 |
| 증강 · 가중치 없음 | 모델 저장, 드라이브 경로 |

### 고려 사항
- 검증셋을 분리하면서 학습 데이터가 전체의 80%로 줄어듦
- 이후 모든 개선 실험에서 **동일한 분할(`split_train.csv`, `split_valid.csv`)**을 사용하여 비교의 공정성 유지

## 4. 한계 → 개선 방향 연결 (Mission 2 후보)

| Baseline 한계 | 개선 방향 후보 | 개선 영역 |
|---|---|---|
| ② 클래스 불균형 미고려 | 클래스 가중치 손실(Weighted Loss), 가중 샘플링 | 학습 방식 |
| ③ 해상도 손실 | 원본 224×224 그대로 사용 | 데이터 |
| ④ 작은 모델 + 짧은 학습 | ImageNet 사전학습 모델 Fine-tuning, epoch 증가 | 모델 / 학습 방식 |
| ⑤ 임계값 고정 | 검증셋 기준 임계값 조정 | 예측 |
| EDA: 검은 여백·몸 크기의 클래스 간 차이 | 내용 영역 Crop 후 리사이즈 | 데이터 |
| EDA: 촬영 조건·자세 다양성 | 데이터 증강 (밝기·대비, 소폭 회전) | 데이터 |
