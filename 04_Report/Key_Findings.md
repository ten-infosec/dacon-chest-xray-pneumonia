## 1. 데이터 특성 (01_EDA)

### 1-1. 클래스 불균형
- 학습 데이터: 정상 1,341장(25.7%) / 폐렴 3,875장(74.3%) → 불균형 **2.89배**
- 전부 "폐렴"으로 예측해도 검증 Accuracy 74.3% → Accuracy만으로는 모델 능력을 판단하기 어려움
- **대응**: 모델 개선 여부는 AUC · Sensitivity · Specificity로 판단, Accuracy는 리더보드 확인용

### 1-2. 파일 정렬
- `train_0001~1341` = 정상, `train_1342~5216` = 폐렴 (완전 정렬)
- **대응**: 층화 분할(Stratified Split) + DataLoader 셔플 필수

### 1-3. 검은 여백과 몸 크기 차이 (지름길 학습 위험)
- 1차 측정(밝기 5 이하 픽셀 비율): 정상 24.7% vs 폐렴 35.6%
- 2차 측정(줄 전체가 검은 행·열 비율): 정상 17.6% vs 폐렴 31.5%
- 두 측정 모두 **폐렴 이미지에서 몸이 화면에서 차지하는 비율이 일관되게 작음**
- 원인(패딩 · 환아 체격 · 촬영 방식)은 환자 · 촬영 정보가 없어 확인 불가
- **위험**: 모델이 폐 병변이 아니라 "검은 면적"을 근거로 판단할 수 있음
- **측정의 한계**: X-ray에서는 패딩과 몸 바깥 공기가 모두 완전 검정으로 찍혀, 단순 밝기로는 둘을 분리할 수 없었음

### 1-4. 기타 관찰
- 대부분 이미지에 `R` 표식 존재 (위치·크기 제각각, 양쪽 클래스 모두)
- 소아 데이터 특성상 자세 · 몸 크기 · 밝기 · 대비가 이미지마다 다름
- 육안으로 정상과 구분하기 어려운 폐렴 사례 존재 (`train_3582`, `train_3631`)

## 2. 학습 · 테스트 분포 차이 (02_Baseline 진단) ⚠️ 핵심 발견

### 2-1. 이미지 형태 차이

| 항목 | 학습 이미지 | 테스트 이미지 |
|---|---|---|
| 크기 | 전부 **224×224** (대회 측 사전 가공) | **1112×736, 1088×576, 1368×904** 등 원본 크기 그대로 |
| 형태 | 정사각형, 검은 여백(패딩)이 덧대진 경우 많음 | 직사각형 원본, 여백 없음 |
| 평균 밝기 (0~255) | **88.7** (600장 샘플) | **121.0** (624장 전체) |

### 2-2. 클래스 비율 차이
- 학습 데이터 폐렴 비율: 74.3%
- 테스트 데이터 폐렴 비율: **약 62.5%** ("전부 폐렴" 제출 시 리더보드 Accuracy 0.625로 확인)
- → 테스트셋은 학습셋보다 정상 비율이 높음

### 2-3. 왜 문제인가
- 모델은 **"여백 있는 정사각형, 어두운 이미지"**로 학습하지만, 시험에서는 **"여백 없고, 리사이즈 시 옆으로 눌리고, 밝은 이미지"**를 받음
- 학습 이미지에서 발견한 **"폐렴일수록 검은 여백이 많다"**는 단서는 테스트 이미지에 존재하지 않음 → 모델이 이 단서에 의존했다면 테스트에서 크게 무너짐
- 테스트셋의 정상 비율이 더 높으므로, 폐렴 쪽으로 기운 모델은 리더보드에서 손해가 큼 → **특이도(정상을 정상으로 맞히는 능력)가 특히 중요**

### 2-4. 규칙 준수 메모
- 테스트 이미지의 크기·밝기를 **관찰**하는 것은 문제 없음
- 테스트 이미지로 정규화 값을 계산하거나, 테스트 비율(62.5%)에 맞춰 임계값을 조정하는 것은 **테스트 정보를 학습·설정에 사용**하는 것 → 하지 않음
- 대응은 **학습 데이터 쪽 처리(Crop, 증강)**와 **검증셋 기반 설정**으로만 진행

### 2-5. 학습된 Baseline으로 분포 차이 재확인

| 항목 | 검증셋 | 테스트셋 |
|---|---|---|
| 폐렴 확률 중앙값 | **0.979** (확신) | **0.503** (반반, 헷갈림) |
| 정상으로 예측한 비율 | 28.6% (299/1,044) | **49.7% (310/624)** |
| 실제 정상 비율 | 25.7% | 약 37.5% |

- 검증셋에서는 확신을 갖고 판단하던 모델이, 테스트에서는 절반 가까이를 0.5 근처로 헷갈려함 → **2-1의 학습·테스트 분포 차이가 학습된 모델의 예측에서 그대로 확인됨**
- 테스트에서 정상으로 예측한 수(310)가 실제 정상 수(약 234)보다 **최소 76장 많음** → 실제 폐렴을 정상으로 판정한 경우가 최소 76장
  - 의료에서 가장 위험한 오류인 **"환자를 놓치는" 오류(False Negative)가 테스트에서 크게 늘었을 가능성**
  - 이 수치로 계산하면 리더보드 Accuracy의 상한은 약 **0.88** ((624 − 76) / 624)
- ※ 테스트 비율을 이용한 계산은 **결과 분석에만** 사용하고, 임계값·설정 조정에는 사용하지 않음

## 3. Baseline의 한계

### 3-1. 코드 구조상 한계 (공식 Baseline 분석)
1. 검증셋 부재 → train loss 외 성능 측정 불가
2. 클래스 불균형 미고려 → 다수 클래스(폐렴) 편향
3. 해상도 손실 → 224×224를 128×128로 축소 (면적 약 1/3)
4. 작은 모델 + 짧은 학습 → Conv 2층, 2 epochs, 사전학습 없음
5. 임계값 고정 → argmax(0.5 기준), 불균형·분포 차이 상황에서 최적이 아닐 수 있음
6. 재현성 장치 부재 → Seed 미고정, 모델 저장 없음

### 3-2. Baseline 학습 결과 (02_Baseline)

**검증 성능** (검증셋 1,044장, 임계값 0.5)

| 지표 | 값 | 해석 |
|---|---|---|
| Accuracy | **0.9454** | "전부 폐렴" 기준 0.7433보다 약 20%p 높음 → 실제로 학습됨 |
| AUC | **0.9832** | 정상/폐렴 구분 능력 매우 높음 |
| Sensitivity | 0.9433 | 폐렴 776명 중 732명 탐지, **44명 놓침** |
| Specificity | 0.9515 | 정상 268명 중 255명 정상 판정, **13명 오진** |
| F1 | 0.9625 | |

**에폭별 변화**

| Epoch | Train Loss | Val Acc | Val AUC |
|---|---|---|---|
| 1 | 0.3137 | 0.9234 | 0.9758 |
| 2 | 0.1660 | 0.9454 | 0.9832 |

**리더보드 성능**
- 리더보드 Accuracy: **0.7468** ("전부 폐렴" 0.625보다 약 12%p 높은 수준)
- 검증 Accuracy 0.9454 대비 **약 19.9%p 하락** → 검증 성능이 실제 성능을 크게 과대평가함을 확인

**학습 결과에서 드러난 한계**
1. **학습 부족**: 1→2 에폭에서 AUC가 0.9758 → 0.9832로 아직 상승 중 → 2 epochs에서 멈춘 것이 아쉬움
2. **예상과 다른 오류 양상**: 불균형 때문에 특이도가 낮을 것으로 예상했으나, 검증셋에서는 특이도(0.95)가 민감도(0.94)보다 높음 → 오히려 놓친 폐렴(44명)이 오진(13명)보다 많음
3. **검증 성능의 과대평가**: 검증셋은 학습셋과 같은 분포(224×224 가공 이미지)라 높은 성능이 나오지만, 테스트에서는 확신도가 크게 떨어짐(2-5) → **검증 성능이 실제 테스트 성능을 대변하지 못함**
4. **테스트에서의 False Negative 증가 가능성**: 테스트에서 정상 예측이 과도하게 많아 환자를 놓치는 위험한 오류가 늘었을 가능성 (2-5)

## 3.5 단계 1 실험 결과: 사전학습 모델 + Fine-tuning 방식 (03_Experiments)

| 실험 | 설정 | Val Acc | Val AUC | Sens | Spec | FN | FP | 테스트 확률 중앙값 | 테스트 정상 예측 비율 | 리더보드 | 검증-리더보드 격차 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| E0 | SimpleCNN 128, 2 ep | 0.9454 | 0.9832 | 0.943 | 0.952 | 44 | 13 | 0.503 | 0.497 | 0.7468 | **19.9%p** |
| E1a | ResNet18 224, fc만 학습 | 0.9646 | 0.9944 | 0.987 | 0.899 | 10 | 27 | 0.592 | 0.471 | 0.8333 | **13.1%p** |
| E1b | ResNet18 224, 전체 미세조정 | 0.9799 | 0.9979 | 0.977 | 0.989 | 18 | 3 | 0.982 | 0.386 | **0.9407** | **3.9%p** |

**해석**
- 리더보드 0.7468 → 0.8333 → **0.9407** (Baseline 대비 +19.4%p)
- **검증-리더보드 격차 19.9%p → 13.1%p → 3.9%p**: 테스트 확률 중앙값이 검증셋 수준(0.98)으로 회복될수록 격차가 줄어듦 → "테스트 확신도"가 분포 차이 극복 정도를 보여주는 지표로 유효
- **Fine-tuning 방식 → 전체 미세조정 채택**
  - E1a는 특이도 0.899(오진 27명), 테스트 확신도 0.592로 Baseline과 큰 차이 없음 → ImageNet 특징을 그대로 쓰는 것만으로는 X-ray 분포 차이를 극복하지 못함
  - E1b는 민감도·특이도 모두 0.97 이상, 테스트 확신도 0.982 → 분포 차이를 줄인 요인은 사전학습 자체보다 **전체 미세조정**
- **남은 과제**: E1b도 624장 중 약 37장 오답. 정상 예측 비율(0.386)은 실제(약 0.375)와 비슷하나 오류가 양방향으로 상쇄된 결과 → 분포 차이가 완전히 해소된 것은 아님 → 단계 2(Crop)의 목표
- **가설 (Grad-CAM 검증 예정)**: 전체 미세조정으로 더 일반적인 폐 특징을 학습하여 검은 여백 같은 단순 단서에 덜 의존하게 되었을 가능성

**주의 사항**
- E1b train loss 0.0125(4 ep) → 0.0161(5 ep) 소폭 상승, 학습 데이터를 거의 다 맞히는 수준 → 과적합 가능성 (E5에서 검토)
- E0(2 epochs)와 E1(5 epochs)은 에폭 수가 달라 개선 폭에 에폭 증가 효과가 일부 포함됨

## 3.6 단계 2 실험 결과: 검은 여백 Crop (03_Experiments) — H1 기각, H1' 확인, H1b 기각 → Crop 미채택

> 생각의 흐름: **가설 → Crop 동작 확인 → 밝기 재측정(2.5단계) → E2 학습 → 예상과 다른 신호 발견 → 새 가설**

### ① 가설 (H1)
- 학습 이미지에만 있는 검은 여백을 잘라내면 → 지름길 단서("검은 면적이 넓으면 폐렴")가 사라지고, 여백 없는 테스트 이미지와 형태가 비슷해져 → **리더보드가 오르고 검증-리더보드 격차(3.9%p)가 줄어들 것**

### ② Crop 동작 확인 (학습 전 육안 검증)
| 샘플 | 제거된 면적 | 확인 |
|---|---|---|
| train_0803 (정상) | 14.7% | 여백 제거, 폐 유지 |
| train_0260 (정상) | 17.6% | 여백 제거, 폐 유지 |
| train_3582 (폐렴) | 36.2% | 위아래 검은 띠 깔끔하게 제거, 폐 유지 |
| train_5089 (폐렴, 기울어짐) | 35.7% | 위아래 띠는 제거, **모서리 검은 삼각형은 남음** |
| test_0001 | 3.7% | 테스트에도 약간의 여백 존재 |
| test_0002 | 7.6% | 〃 |

- **폐 영역이 잘린 사례 없음** → Crop 함수 사용 가능 판단
- **한계**: "줄 전체가 검은 행·열"만 자르는 방식이라 기울어진 이미지의 모서리 삼각형은 제거하지 못함

### ③ 2.5단계: Crop 후 밝기 재측정 🎯
| | 학습 (600장 샘플) | 테스트 (624장) | 차이 |
|---|---|---|---|
| Crop 전 | 87.6 | 121.0 | 33.4 |
| Crop 후 | 121.0 | 122.1 | **1.1 (97% 감소)** |

- **왜 측정했나**: Baseline 진단에서 발견한 밝기 차이(88.7 vs 121.0)가 "실제로 테스트 이미지가 밝은 것"인지, "학습 이미지의 검은 여백(밝기 0)이 평균을 끌어내린 것"인지 구분하기 위해
- **결과**: 밝기 차이의 **97%가 검은 여백 때문**이었음 → 실제 밝기 차이는 거의 없음
- **판단 (Mission 2 설계의 2.5단계 기준 적용)**: Crop 후 차이가 거의 없으므로 → **S2(밝기 대응)는 가볍게 진행**. 원래 계획(CLAHE vs 증강 본격 비교)을 측정 결과에 따라 조정함
- **의미**: "학습 데이터가 어둡다"는 첫 관찰은 사실 **여백이라는 하나의 원인**이 만든 두 개의 증상(검은 면적 차이 + 밝기 차이) 중 하나였음

### ④ E2 학습 결과: 검증은 최고, 테스트 쪽 경고 ⚠️

|---|---|---|---|---|---|---|---|---|---|

| Epoch | Train Loss | Val Acc | Val AUC | Sens | Spec |
|---|---|---|---|---|---|
| 1 | 0.0961 | 0.9875 | 0.9967 | 0.992 | 0.974 |

- **검증 지표는 모든 항목에서 E1b보다 좋아짐** (놓친 폐렴 18 → 11명, 오진 3 → 2명)
- **그런데 테스트에서 이상 신호**
  - 테스트 정상 예측 비율 **0.284** (실제 정상 비율 약 0.375)
  - 정상 예측 약 177장 vs 실제 정상 약 234장 → **정상을 폐렴으로 오진한 경우가 최소 약 57장**
  - → 리더보드 상한 약 **0.91** ((624 − 57) / 624) → **E1b(0.9407)보다 떨어질 가능성**
  - 테스트 확률 중앙값 **1.000** → 테스트 이미지에서 지나치게 확신 (과신)
- Epoch 1부터 Val Acc 0.9875로 매우 빠르게 높아짐, Train Loss 0.0025까지 하락 → 학습 데이터를 거의 완벽히 맞히는 상태

**리더보드 결과로 확인 ✅**
| 실험 | 검증 Acc | 리더보드 | 검증-리더보드 격차 |
|---|---|---|---|
| E1b | 0.9799 | 0.9407 | 3.9%p |
| E2 | 0.9875 | **0.9022** | **8.5%p** |
- 리더보드 **0.9407 → 0.9022 (−3.85%p)**, 격차 3.9%p → **8.5%p로 확대**
- 테스트 간접 지표로 예측했던 상한(약 0.91)과 일치 → **리더보드에 내기 전에 간접 지표로 하락을 예측할 수 있었음**
- 624장 중 약 61장 오답 (E1b 약 37장보다 24장 증가)
- **결론: 가설 H1("Crop하면 리더보드가 오르고 격차가 줄어든다")은 기각.** 검증 성능은 올랐지만 테스트 성능은 떨어짐
- 리더보드 최종 선택은 E1b 유지

### ⑤ 예상과 다른 이유: 새로운 지름길 가설 (H1')
- **단서**: Crop 비교 이미지의 크기
  - 정상 Crop 결과: 221×187, 211×184 → **정사각형에 가까움**
  - 폐렴 Crop 결과: 224×143, 224×144 → **옆으로 넓적함**
  - 테스트 원본: 1936×1554, 1612×941 등 → **역시 넓적함**
- **추론 과정**
  1. Crop한 이미지는 모두 `Resize(224, 224)`로 정사각형이 됨
  2. 넓적한 폐렴 이미지는 이 과정에서 **세로로 늘어남**, 정사각형에 가까운 정상 이미지는 거의 안 늘어남
  3. 모델이 **"세로로 늘어난 이미지 = 폐렴"**이라는 새 단서를 배웠을 가능성
  4. 테스트 이미지는 대부분 넓적 → 똑같이 늘어남 → **폐렴 쪽으로 기울어짐** (정상 예측 비율 0.284, 확신도 1.000과 일치)
- **해석**: 검은 여백이라는 지름길을 없앴더니, 그 여백이 가려주던 **가로세로 비율 차이라는 다른 지름길**이 드러난 셈
  - E1b까지는 학습 이미지가 모두 패딩된 정사각형이라 "늘어남" 단서가 학습 데이터에 없었음
  - 패딩은 사실 "원래는 넓적했던 이미지를 정사각형으로 맞추기 위해 덧댄 것" → **여백 차이 = 원본 비율 차이**의 다른 모습이었을 가능성
- **검증 방법**: Crop 후 가로세로 비율을 학습 정상 / 학습 폐렴 / 테스트로 나눠 비교 (진단 셀)
  - 폐렴 비율이 정상보다 확연히 크고, 테스트가 폐렴 쪽과 비슷하면 → 가설 확인 → **E2b: 비율을 유지한 채 크기를 맞추는 방식**으로 Crop 수정
- **상태**: 비율 진단으로 확인됨 (아래 ⑥)

### ⑥ 가로세로 비율 진단 결과 → 가설 H1' 확인 ✅
| 그룹 | 평균 | 중앙값 | 하위 10% | 상위 10% |
|---|---|---|---|---|
| 학습 정상 | 1.19 | 1.19 | 1.04 | 1.35 |
| 학습 폐렴 | **1.47** | **1.45** | 1.21 | 1.75 |
| 테스트 (전체) | **1.46** | **1.44** | 1.17 | 1.75 |
- Crop 후 학습 폐렴은 정상보다 확연히 넓적하고(1.47 vs 1.19), **테스트 이미지는 폐렴과 거의 같은 비율(1.46)**
- → 224×224로 맞출 때 "넓적해서 세로로 늘어난 이미지 = 폐렴"이라는 단서가 학습되고, 테스트 이미지는 정상이든 폐렴이든 모두 넓적하므로 폐렴 쪽으로 기울어짐 → E2의 정상 예측 비율 0.284, 리더보드 하락과 일치
- **근본 원인 정리**: 원본 비율 차이(정상은 정사각형에 가깝고 폐렴은 넓적) → 대회 측이 정사각형으로 맞추며 덧댄 **패딩 양의 차이** → EDA에서 본 **검은 영역 차이**와 **밝기 차이**. 즉 지금까지 본 여러 현상은 **하나의 원인(원본 가로세로 비율)**에서 나온 증상들
- **다음 실험 E2b**: 비율 정보 자체를 없애야 함
  - 비율을 유지하고 패딩하면 → 패딩 양이 다시 단서가 됨
  - 그냥 늘이면 → 늘어난 정도가 단서가 됨 (E2)
  - → **모든 이미지를 같은 비율(1.3)로 가운데를 잘라낸 뒤** 224×224로 맞춤 → 모든 이미지가 똑같이 변형되므로 비율이 단서가 될 수 없음


### ⑧ 재현성 확인 (Run all 재실행) ✅
- 새 노트북에서 **세션 처음부터 Run all**로 E1a·E1b·E2를 다시 학습
- 결과표의 모든 값(Val Acc·AUC·Sens·Spec·FN·FP·테스트 정상 예측 비율·확률 중앙값)이 **이전 실행과 소수점까지 완전히 동일**
- → Seed 고정 + DataLoader 셔플·worker Seed 고정 + cudnn deterministic 설정으로 **필수 규칙 2(재현성)를 실제로 확인**

### ⑨ E2b: Crop + 고정 비율(1.3) 중앙 Crop — 가설 H1b
- **가설**: 모든 이미지를 같은 비율로 맞추면 "늘어남 = 폐렴" 단서가 사라져 테스트 성능이 회복될 것
| 실험 | Val Acc | Val AUC | Sens | Spec | FN | FP | 테스트 확률 중앙값 | 테스트 정상 예측 비율 | 리더보드 |
|---|---|---|---|---|---|---|---|---|---|
| E1b | 0.9799 | 0.9979 | 0.977 | 0.989 | 18 | 3 | 0.982 | 0.386 | 0.9407 |
| E2 | 0.9875 | 0.9988 | 0.986 | 0.993 | 11 | 2 | 1.000 | 0.284 | 0.9022 |
| **E2b** | 0.9713 | 0.9967 | 0.969 | 0.978 | 24 | 6 | 0.998 | **0.296** | **0.8990** |

**에폭별 변화 (E2b)**
| Epoch | Train Loss | Val Acc | Val AUC | Sens | Spec |
|---|---|---|---|---|---|
| 1 | 0.1252 | 0.9693 | 0.9954 | 0.991 | 0.907 |
| 2 | 0.0398 | 0.9761 | 0.9959 | 0.985 | 0.951 |
| 3 | 0.0249 | 0.9713 | **0.9967** | 0.969 | 0.978 |
| 4 | 0.0160 | 0.9808 | 0.9963 | 0.982 | 0.978 |
| 5 | 0.0280 | 0.9684 | 0.9961 | 0.966 | 0.974 |

**해석**
- 테스트 정상 예측 비율 0.284 → **0.296**으로 거의 회복되지 않음 (E1b 0.386, 실제 약 0.375) → 간접 지표 기준 리더보드 상한 약 0.92 → **E1b보다 낮을 것으로 예상**
- 검증 성능도 E1b·E2보다 낮아짐 (FN 24, FP 6) → 가운데만 잘라내면서 폐 가장자리 정보 일부를 잃었을 가능성
- **리더보드 0.8990** (E1b 0.9407 대비 −4.2%p, E2 0.9022보다도 낮음), 검증-리더보드 격차 7.2%p → 간접 지표 예측(상한 약 0.92 이하)과 일치
- **결론**: 비율을 통일해도 테스트 쏠림이 해결되지 않음 → **가설 H1b 기각 확정**. 가로세로 비율이 원인의 일부였을 수는 있지만, Crop 계열 전처리가 만드는 학습-테스트 차이는 비율만으로 설명되지 않음
- **아직 설명되지 않은 부분**: Crop을 하지 않은 E1b는 테스트 쏠림이 적었는데(0.386), Crop을 한 두 실험(E2, E2b)은 모두 0.28~0.30으로 쏠림 → "Crop 자체"가 학습 이미지와 테스트 이미지의 다른 차이(확대 정도, 해상도 처리 방식 등)를 키웠을 가능성. 학습 이미지는 이미 224로 축소된 것을 잘라서 **다시 확대**하는 반면, 테스트 이미지는 고해상도 원본을 **축소**하므로 선명도가 다를 수 있음 (미확인 가설)

### ⑩ 단계 2 결론 및 방향 전환
- Crop 계열 2개 실험(E2, E2b) 모두 검증 성능과 무관하게 테스트에서 폐렴 쪽으로 쏠림 → **Crop 전략은 이번 데이터에서 채택하지 않음**
- 단계 2에서 얻은 것: ① 밝기 차이의 97%가 여백 때문이라는 원인 규명 ② 여백·밝기·비율 차이의 공통 원인(원본 비율) 규명 ③ 테스트 간접 지표로 리더보드 하락을 사전에 예측하는 방법 ④ 재현성 확인
- **다음 단계 기본 설정은 E1b로 복귀**, 학습 방식 전략(클래스 가중치 손실, 학습률·스케줄러) 위주로 진행
- 밝기 대응(단계 3)은 Crop을 쓰지 않으면 여백이 남아 있는 상태 → 밝기 차이의 대부분이 여백 때문이므로 별도 대응 우선순위 낮음

### ⑪ 이 단계에서 배운 점
- **검증 점수가 좋아져도 테스트에서는 나빠질 수 있음** → 검증셋은 학습셋과 같은 분포라 새 지름길을 잡아내지 못함. 테스트 확률 중앙값·정상 예측 비율 같은 **간접 지표를 함께 봐야** 함
- **한 가지 문제를 고치면 숨어 있던 다른 문제가 드러날 수 있음** → 전처리 하나를 바꿀 때마다 "모델이 새로 이용할 수 있는 단서가 생기지 않았는지" 점검해야 함
- **여러 증상의 공통 원인을 찾기** → 검은 영역·밝기·비율 차이는 모두 '원본 가로세로 비율'이라는 하나의 원인에서 나왔음. 증상 하나씩 고치기보다 원인을 찾아야 함
- **측정해 보고 계획을 바꾸는 것**의 가치 → 밝기 문제는 실제로 거의 없었고, 측정 없이 CLAHE를 적용했다면 존재하지 않는 문제를 고치느라 시간을 썼을 것

## 6. 아직 확인하지 못한 것 / 한계

- 원본 데이터는 한 환자가 여러 장 촬영된 경우가 있으나 파일명이 익명화되어 **환자 단위 분리 불가** → 검증 성능이 실제보다 높게 나올 수 있음
- 검은 여백 · 몸 크기 차이의 정확한 원인 (패딩 · 체격 · 촬영 방식) → 10/7 확인: 여백·밝기 차이는 **원본 가로세로 비율 차이**(정상 1.19 vs 폐렴 1.47, Crop 후 기준)에서 비롯됨. 그 비율 차이 자체의 원인(촬영 장비·자세·나이)은 정보가 없어 확인 불가
- Crop 방식의 한계: 기울어진 이미지의 모서리 검은 삼각형은 제거되지 않음
- ImageNet 사전학습 가중치 사용이 "외부 데이터 사용 금지" 규칙에 해당하지 않는지 운영진 확인 필요
