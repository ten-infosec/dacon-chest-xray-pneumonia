# Mission 0. 문제 해결 전략 수립 (Flow Planning)

> 작성: 2026.10.05 / 보완: 2026.10.07 (대회 평가 지표 확인 결과 반영)

---

## 1. 문제 정의
- 흉부 X-ray 이미지를 보고 정상(NORMAL, 0) / 폐렴(PNEUMONIA, 1)을 분류하는 **이진 분류** 문제
- 의료 진단 보조가 목적이므로, 폐렴 환자를 놓치지 않는 것(민감도)이 특히 중요

## 2. 평가 지표
| 구분 | 지표 | 용도 |
|---|---|---|
| 대회 공식 지표 | **Accuracy** | 리더보드 채점 (0/1 제출) |
| 모델 평가 (주) | **ROC-AUC** | 임계값과 무관하게 정상/폐렴을 구분하는 능력 |
| 모델 평가 (보조) | Sensitivity · Specificity · F1 · Confusion Matrix | 어떤 종류의 실수를 하는지 확인 |

**선택 이유**
- 클래스 불균형이 예상되어(실측 폐렴 74.3%), 전부 폐렴으로 찍어도 Accuracy가 높게 나옴 → Accuracy만으로는 모델 능력을 판단하기 어려움
- 대회는 Accuracy로 채점하므로 리더보드 확인용으로 함께 사용하되, **모델 개선 여부는 AUC와 민감도·특이도로 판단**

## 3. Baseline 이전에 예상한 문제
1. **클래스 불균형** → 다수 클래스(폐렴)로 치우친 예측
2. **데이터 양 부족** → 처음부터 학습 시 과적합 위험
3. **검증 데이터 부재·편향** → 검증셋이 없거나 작으면 성능 평가를 신뢰하기 어려움

## 4. 개선 가설 (초기)
- **가설 1**: 클래스 가중치(Weighted Loss)를 적용하면 소수 클래스(정상) 예측이 개선되어 AUC와 Specificity가 오를 것이다
- **가설 2**: ImageNet 사전학습 모델 + 데이터 증강을 적용하면 적은 데이터로도 일반화 성능이 향상될 것이다

> 이후 EDA·Baseline 결과(학습·테스트 분포 차이 발견)를 보고 **Crop · CLAHE/증강을 우선순위로 올리는 방향으로 가설을 수정**함 → Mission 1 결과 정리, `03_Experiments.ipynb` Mission 2 설계 참고

## 5. 전체 흐름
데이터 탐색(EDA) → Baseline 재현·평가 → 문제점 도출 → 개선 전략 설계 → 단계별 실험(한 번에 하나씩) → Baseline vs 개선 모델 비교 → 오답 분석 → Grad-CAM 해석 → 결과 데이터·Risk Level 정의 → 최종 파이프라인·보고서

## 6. 먼저 적용할 전략과 이유
- **사전학습 모델(ResNet18) + 224 해상도**를 가장 먼저 적용 → Baseline의 모델 용량·해상도 한계가 가장 기본적인 제약이라고 판단, 이후 전략들의 공통 출발점으로 삼기 위함
- 그다음 데이터 쪽 문제(검은 여백·밝기)를 겨냥한 전처리, 마지막으로 학습 방식(가중치 손실, 학습 설정) 순서

## 7. 검증 방법
- train을 **층화 분할(8:2)**하여 검증셋 구성, 분할 결과를 파일(`split_train.csv`, `split_valid.csv`)로 고정해 모든 실험에 동일 적용
- **Seed 고정**(42)으로 재현성 확보
- 실험마다 설정·결과를 `results.csv`에 기록하여 Baseline과 비교
- **검증 점수와 리더보드 점수를 함께 기록** → 두 점수의 격차가 줄어드는지도 개선 지표로 사용
- 검증셋은 평가·최고 에폭 선택에만 사용하고 학습에는 사용하지 않음 (Data Leakage 방지)
